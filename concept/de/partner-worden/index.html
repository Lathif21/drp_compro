Vom Link bis zur Auszahlung

Keine Vorgaben und kein Mindestmaß. Sie teilen Ihren Link, wann immer es Ihnen passt.

  1. Fordern Sie Ihren Link anFüllen Sie das untenstehende Formular aus. Sie erhalten einen persönlichen Link, der Ihren individuellen Code enthält.
  2. Teilen Sie dies mit Ihrem PublikumWer über Ihren Link ein Angebot anfordert, erhält automatisch 10 % Rabatt.
  3. Der Kunde begleicht die RechnungSobald die Rechnung im Kundenportal beglichen ist, stehen Ihnen Ihre 5 % fest zu. Bei Zahlungseingang, nicht auf Anfrage.
  4. Monatliche AuszahlungIn Ihrem persönlichen Dashboard können Sie jeden Klick, jede Anfrage und jede Provision nachverfolgen. Was Sie in einem Monat verdienen, wird Ihnen im darauffolgenden Monat ausgezahlt.

Was Partner fragen

Die kurzen Antworten.

Wer kann Partner werden?

Alle, deren Zielgruppe aus Unternehmern besteht: Influencer, Berater, Steuerberater, Coaches, Netzwerker. Sie benötigen keine große Reichweite, sondern lediglich eine Zielgruppe, für die eine maßgeschneiderte Website sinnvoll ist. Wir prüfen jede Anfrage persönlich.

Wann erhalte ich meine Provision?

Erst wenn der Kunde die Rechnung tatsächlich über das Kundenportal begleicht. Eine Anfrage oder ein genehmigter Kostenvoranschlag bringt noch keine Einnahmen: Wir zahlen auf der Grundlage der tatsächlichen Zahlungseingänge, nicht auf der Grundlage von Zusagen.

Auf welcher Grundlage werden die 5 % berechnet?

Auf den Betrag, den der Kunde tatsächlich bezahlt, also nach Abzug des 10-prozentigen Rabatts, den er über Ihren Link erhalten hat, und ohne Mehrwertsteuer. Wird ein Projekt in Raten in Rechnung gestellt, erhalten Sie eine Provision für jede bezahlte Rate.

Was passiert, wenn jemand zwei Partnerlinks verwendet?

Der erste Link ist entscheidend. Ein Link läuft nicht ab: Wer ihn angeklickt hat, bleibt mit diesem Partner verbunden, bis wir den Link widerrufen, und ein späterer Link überschreibt ihn nicht.

Wie kann ich nachverfolgen, was ich verdient habe?

Sie erhalten ein Dashboard mit Ihren Klicks, Anfragen, bezahlten Rechnungen und ausstehenden Provisionen. Was Sie in einem Kalendermonat verdienen, wird im darauffolgenden Monat per Banküberweisung ausgezahlt.
