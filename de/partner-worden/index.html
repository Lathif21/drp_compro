Häufig gestellte Fragen

Was Partner
normalerweise fragen.

Wer kann Marketingpartner werden?

Alle, deren Zielgruppe aus Unternehmern besteht: Social-Media-Experten, Berater, Steuerberater, Coaches, Netzwerker. Sie brauchen keine große Reichweite – Sie brauchen eine Zielgruppe, für die eine maßgeschneiderte Website sinnvoll ist. Wir prüfen jede Bewerbung persönlich.

Wann erhalte ich meine Provision?

Erst wenn der Kunde die Rechnung tatsächlich im Kundenportal bezahlt. Eine Anfrage oder sogar ein genehmigter Kostenvoranschlag bringt noch keine Einnahmen: Wir zahlen erst aus, wenn das Geld eingegangen ist, nicht aufgrund von Versprechungen. Auf diese Weise entsteht niemals eine Provision für eine Rechnung, die nie bezahlt wird.

Auf welcher Grundlage werden die 5 % berechnet?

Auf den Betrag, den der Kunde tatsächlich bezahlt – also nach Abzug des 10-prozentigen Rabatts, den Ihr Link ihm verschafft hat, und ohne Mehrwertsteuer. Bei einem Projekt, das in Etappen abgerechnet wird, erhalten Sie eine Vergütung für jede bezahlte Etappe.

Was passiert, wenn jemand über zwei Partnerlinks auf die Seite gelangt?

Der erste Link zählt. Ein Link bleibt ab dem Klick 90 Tage lang gültig, und während dieser Zeit wird er nicht durch einen späteren Link überschrieben. Dadurch wird verhindert, dass jemand eine bestehende Empfehlung in letzter Minute an sich reißt.

Wie kann ich nachverfolgen, was ich verdient habe?

Sie erhalten Zugriff auf ein Dashboard, in dem Ihre Klicks, Anfragen, bezahlten Rechnungen und ausstehenden Provisionen angezeigt werden. Die in einem Kalendermonat erzielten Einnahmen werden im darauffolgenden Monat per Banküberweisung ausgezahlt.
